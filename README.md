# PhotoPortfolio — Персональное портфолио фотографа

Учебный проект, выполненный в рамках лабораторной работы №2 по дисциплине "Интернет-технологии и Веб Программирование". Проект представляет собой концепт и структуру сайта-портфолио профессионального фотографа.

## 🛠 Технологии и инструменты
* **Дизайн:** Figma (Мудборд, палитра, типографика, прототип).
* **Разметка и стили:** HTML5, CSS3.
* **Скрипты:** JavaScript (ES6+).
* **Среда выполнения:** Node.js & npm.
* **Контроль версий:** Git & GitHub.
* **Форматирование:** Prettier.

## 📁 Структура проекта
* `css/` — таблицы стилей.
* `js/` — клиентские скрипты.
* `assets/` — шрифты и статические файлы.
* `images/` — графический контент (галерея и иконки).
* `design/` — ссылка на макет и материалы проектирования.

## 🚀 Запуск проекта
1. Установите зависимости (если необходимо): `npm install`.
2. Откройте `index.html` в браузере или используйте расширение **Live Server** в VS Code.
